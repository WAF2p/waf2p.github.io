Twoje dane w dowolnym hoście MCP.

WAF++ MCP Bridge udostępnia REST API WAFPass jako narzędzia Model Context Protocol dla asystentów AI. Poproś Claude o listę przebiegów, analizę wyników lub eksplorację danych zgodności — wszystko w tej samej sesji SSO i z tymi samymi uprawnieniami opartymi na rolach, którym już ufasz.

Dodatkowe poświadczenia

Bezpieczny most, a nie drugi system uwierzytelniania.

Most wykorzystuje tożsamość, uprawnienia i ścieżki audytu WAFPass. Weryfikuje, przekazuje i filtruje — nigdy nie przechowuje sekretów chmurowych ani haseł IdP.

Niezależny od IdP

Brak bezpośredniej integracji z Keycloak, Entra czy Okta. Most ufa tokenom wydanym przez wafpass-server, który już obsługuje przepływy OIDC i SAML.

Introspekcja tokenów

Każde nowe połączenie SSE jest weryfikowane przez GET /auth/me. Natychmiastowe wykrywanie unieważnień i brak konieczności współdzielenia sekretów JWT.

Narzędzia z minimalnymi uprawnieniami

tools/list jest filtrowane według roli uwierzytelnionego użytkownika. Endpointy tylko dla administratorów są niewidoczne dla inżynierów, a autoryzacja na poziomie wierszy obowiązuje przy każdym wywołaniu backendu.

Przekazywanie kontekstu

Oryginalny nagłówek Authorization: Bearer jest przekazywany do WAFPass przy każdym żądaniu, co zachowuje tożsamość użytkownika i przypisanie w audycie.

Generowane z OpenAPI

Przy starcie most pobiera /openapi.json i rejestruje bezpieczne operacje jako typowane narzędzia MCP z argumentami walidowanymi przez Pydantic.

stdio lub SSE

Uruchom most jako lokalny proces stdio dla Claude Desktop albo udostępnij go przez HTTP/SSE zdalnym hostom MCP i klientom w przeglądarce.

Połącz Claude Desktop w kilka minut.

Zainstaluj most, zaloguj się raz i wskaż Claude Desktop polecenie stdio. Bez certyfikatów, bez otwartych portów, bez dodatkowego uwierzytelniania.

1. Instalacja i konfiguracja 
git clone https://github.com/WAF2p/wafpass-mcp.git
cd wafpass-mcp
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"

wafpass-mcp-configure
# Enter WAFpass API URL, username and password
2. Konfiguracja Claude Desktop (stdio) 
{
  "mcpServers": {
    "wafpass": {
      "command": "/path/to/wafpass-mcp/.venv/bin/wafpass-mcp-stdio"
    }
  }
}
3. Docker Compose (alternatywa) 
# From the WAF++ repository root
docker compose up -d wafpass-mcp
docker compose logs -f wafpass-mcp

# SSE endpoint: http://localhost:3001/sse
# Override WAFPASS_TOKEN_MODE or WAFPASS_JWT_SECRET in .env

Jak działa most.

Użytkownik uwierzytelnia się przez nadrzędny IdP, wymienia tokeny z WAFPass, a następnie przekazuje ten sam token Bearer do hosta MCP. Most przekazuje żądania i filtruje narzędzia według roli.
