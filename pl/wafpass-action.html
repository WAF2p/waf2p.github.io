Zgodność w Twoim potoku.

Dodaj WAF++ PASS do dowolnego workflow. Skanuj Terraform, Bicep, CDK lub Pulumi przy każdym pull requeście i pushu, a następnie wysyłaj pełny wynik na serwer WAFPass na potrzeby pulpitów, analizy luk i dowodów audytowych.

Jeden krok. Pełna widoczność.

Action zajmuje się instalacją CLI, skanowaniem, wysyłką wyników i egzekwowaniem zasad, aby Twój zespół mógł skupić się na wdrażaniu.

Automatyczna instalacja CLI

Automatycznie instaluje najnowszy wafpass-core z PyPI — lub użyj własnego źródła pip albo preinstalowanego pliku binarnego.

Skan wielu IaC

Skanuj pliki Terraform, Bicep, CDK lub Pulumi w jednym kroku. Obsługuje wiele ścieżek oraz JSON planu Terraform do przeglądu zmian.

Wysyłka na serwer

Wysyła pełny wafpass-result.json do POST /api/v1/runs , aby pulpity i pakiety dowodów były zawsze aktualne.

Bramki zasad

Konfigurowalne zasady fail_on od never do critical. Krok kończy się niepowodzeniem dopiero po bezpiecznym zapisaniu wyniku na serwerze.

Elastyczne uwierzytelnianie

Użyj tokenu Bearer dla użytkowników interaktywnych lub klucza API do ingestu dla bezobsługowych przebiegów CI/CD. Oba są bezpiecznie przekazywane na serwer.

Metadane CI/CD

Oznacza przebiegi jako is_cicd: true z triggered_by: github-actions i automatycznie przekazuje gałąź, SHA commita, projekt i etap.

Dodaj ją do dowolnego workflow.

Pobierz repozytorium, uruchom action i pokazuj wyniki zgodności tam, gdzie Twój zespół już pracuje.

.github/workflows/wafpass.yml
{% raw %}
name: WAF++ PASS Scan

on:
  push:
    branches: [main, develop]
  pull_request:

jobs:
  wafpass:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Run WAF++ PASS
        uses: WAF2p/wafpass-action@v0.1.1
        with:
          server_url: ${{ vars.WAFPASS_SERVER_URL }}
          api_key: ${{ secrets.WAFPASS_API_KEY }}
          scan_path: ./infra
          iac_framework: terraform
          project: ${{ github.repository }}
          stage: ${{ github.ref_name == 'main' && 'prod' || 'dev' }}
          fail_on: high
          upload_source: true
{% endraw %}
