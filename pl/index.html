Pierwszy wynik w 2 minuty

Trzy kroki do pierwszego skanu.

01
Zainstaluj CLI

Jedna paczka PyPI daje Ci silnik analizy statycznej.

pip install wafpass-core
02
Uruchom jedno polecenie

Skieruj WAFPass na folder Terraform i uzyskaj podsumowanie JSON.

wafpass check . --output json | jq '.summary'
03
Zobacz, co jest nie tak

Jasna liczba pass/fail i wyniki dla każdej kontroli dokładnie wskazują, co naprawić.

Jak wygląda pierwsze znalezisko

WAFPass oznacza publiczny bucket S3 i pokazuje dokładną kontrolę oraz poprawkę.

FAIL SEC-S3-001

Blok publicznego dostępu do bucketa S3 jest wyłączony. Publiczne bucketi narażają dane na dostęp z internetu.

Fragment poprawki
resource "aws_s3_bucket_public_access_block" "public" {
  bucket                  = aws_s3_bucket.public.id
  block_public_acls       = true
  block_public_policy     = true
  ignore_public_acls      = true
  restrict_public_buckets = true
}

Jak to działa?

Od kodu do zgodności w trzech etapach.

01
Napisz Terraform

Zbuduj infrastrukturę - jako kod - tak jak już to robisz. WAF++ pozostaje poza zakresem pracy.

02
Uruchom WAFPass

Analiza statyczna sprawdza wszystkie zasoby pod kątem WAF++ - nie są potrzebne dane o chmurze.

03
Zgodność statku

Eksport raportów PDF, blokowanie naruszeń w CI, i udowodnić zarządzanie do audytorów.
