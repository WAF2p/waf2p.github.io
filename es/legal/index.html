Aspectos legales y licencias.

WAF++ utiliza un modelo de doble licencia: Apache License 2.0 para el código y Creative Commons Attribution 4.0 (CC BY 4.0) para la documentación. Este modelo es compatible con la CNCF y está preparado para una fundación.

Dos licencias, un framework.

El modelo de doble licencia mantiene WAF++ abierto, utilizable comercialmente y preparado para la CNCF, sin ambigüedades sobre lo que puedes hacer con él.

Código → Apache 2.0

Todo el código fuente, las herramientas y los componentes del framework, incluido WAFPass. Se permiten expresamente el uso comercial, la modificación y la redistribución. Incluye concesión de patentes.

Documentación → CC BY 4.0

Todo el contenido escrito, guías, documentación de los pilares, diapositivas y material de referencia. Compártelo y adáptalo libremente: se requiere atribución a WAF++.

Contribuciones

Al enviar un pull request, aceptas que tu contribución se publique bajo la licencia correspondiente del proyecto (Apache 2.0 para el código, CC BY 4.0 para la documentación).

Apache License 2.0.

Todo el código fuente de WAF++, WAFPass, los plugins y las herramientas se publican bajo la Apache License 2.0, una de las licencias open source más permisivas y extendidas.

Permitido

Uso comercial

Usa WAFPass y todo el código del framework en productos comerciales, herramientas internas y ofertas SaaS sin regalías ni restricciones.

Permitido

Modificación y redistribución

Haz fork, modifica y redistribuye el código libremente. Puedes distribuir versiones modificadas con tus propios términos siempre que se mantenga la licencia original.

Incluido

Concesión explícita de patentes

Los contribuidores otorgan una licencia de patente explícita y libre de regalías sobre cualquier patente aplicable a sus contribuciones, lo que protege a los usuarios posteriores.

No requerido

Sin obligaciones copyleft

No tienes obligación de publicar tu propio código al usar componentes de WAF++. Las integraciones propietarias están plenamente permitidas.

Ver la licencia Apache 2.0 completa

Creative Commons BY 4.0.

Toda la documentación de WAF++, las guías de los pilares, las diapositivas, el material de referencia y el contenido escrito se publican bajo CC BY 4.0.

Qué puedes hacer

  • Compartir — copiar y redistribuir el material en cualquier medio o formato
  • Adaptar — remezclar, transformar y crear a partir del material
  • Uso comercial — usar la documentación con cualquier fin, también comercial

Una condición

  • Atribución obligatoria — debes reconocer adecuadamente a WAF++, enlazar la licencia e indicar si se realizaron cambios.
Ejemplo: «Basado en la documentación de WAF++, CC BY 4.0 — waf2p.dev»

Exención de responsabilidad y contribuciones.

Contexto legal importante para usar WAF++ y contribuir a él.

Exención de responsabilidad

WAF++ se proporciona «tal cual», sin garantías expresas ni implícitas. El uso del framework es bajo tu propia responsabilidad.

El framework no sustituye el asesoramiento jurídico, la certificación formal ni las evaluaciones de cumplimiento. Ofrece orientación, modelos de evaluación y criterios trazables.

Contribuciones y cumplimiento

Al enviar un pull request, aceptas que tu contribución se publique bajo la licencia aplicable del proyecto:

  • Contribuciones de documentación → CC BY 4.0
