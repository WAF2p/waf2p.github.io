Texto de presentación aprobado.

Usa los siguientes textos para describir WAF++ en artículos, podcasts o presentaciones.

Corto (1 frase)

WAF++ es un framework open source y neutral respecto al proveedor para evaluar y mejorar la calidad de las cargas de trabajo cloud en 8 pilares: Security, Reliability, Performance Efficiency, Cost Optimisation, Operational Excellence, Sustainability, Sovereign y Agentic.

Redes sociales / formato corto (≤ 280 caracteres)

WAF++ es un framework open source y neutral respecto al proveedor para la calidad de arquitecturas cloud: 8 pilares, puntuación transparente y gobernanza comunitaria mediante RFC públicas. Docs bajo CC BY 4.0, código bajo Apache 2.0. waf2p.dev

Estándar (2–3 frases)

WAF++ (Well-Architected Framework Plus Plus) es un framework open source impulsado por la comunidad para evaluar y mejorar la calidad de las cargas de trabajo cloud. Abarca 8 pilares —Security, Reliability, Performance Efficiency, Cost Optimisation, Operational Excellence, Sustainability, Sovereign y Agentic— con un modelo de puntuación transparente llamado PASS.

A diferencia de los frameworks propietarios de los proveedores, WAF++ se gobierna abiertamente mediante RFC en GitHub Discussions, de modo que cada decisión es trazable y cada control citable. El framework es libre de usar, de contribuir y de ampliar.

Introducción para podcast / entrevista

WAF++ —se pronuncia «waf plus plus»— es un framework open source que ofrece a los equipos de ingeniería y arquitectura una perspectiva neutral respecto al proveedor para evaluar cargas de trabajo cloud. Lo organiza todo en ocho pilares: Security, Reliability, Performance Efficiency, Cost Optimisation, Operational Excellence, Sustainability, Sovereign y Agentic.

Lo que distingue a WAF++ es cómo se construye: cada directriz, regla de puntuación y decisión de diseño pasa por un proceso RFC público en GitHub, totalmente transparente y totalmente impulsado por la comunidad. No hay ningún proveedor detrás, ni ventas adicionales, ni cajas negras. Cualquiera puede leer los criterios, cuestionarlos y mejorarlos.
