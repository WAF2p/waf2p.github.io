Freigegebene Boilerplate.

Verwenden Sie die folgenden Texte, wenn Sie Wombat in Artikeln, Podcasts oder Präsentationen beschreiben.

Kurz (1 Satz)

Wombat (ehemals bekannt als WAF++) ist ein quelloffenes, anbieterneutrales Framework zur Bewertung und Verbesserung der Qualität von Cloud-Workloads über 8 Säulen: Security, Reliability, Performance Efficiency, Cost Optimisation, Operational Excellence, Sustainability, Sovereign und Agentic.

Social / Kurzform (≤ 280 Zeichen)

Wombat ist ein quelloffenes, anbieterneutrales Framework für die Qualität von Cloud-Architekturen — 8 Säulen, transparentes Scoring, Community-Governance über öffentliche RFCs. Doku unter CC BY 4.0, Code unter Apache 2.0. www.wombat-gov.dev

Standard (2–3 Sätze)

Wombat ist ein quelloffenes, Community-getriebenes Framework zur Bewertung und Verbesserung der Qualität von Cloud-Workloads. Es umfasst 8 Säulen — Security, Reliability, Performance Efficiency, Cost Optimisation, Operational Excellence, Sustainability, Sovereign und Agentic — mit einem transparenten Scoring-Modell namens PASS.

Anders als proprietäre Frameworks von Anbietern wird Wombat offen über RFCs in GitHub Discussions gesteuert — jede Entscheidung ist nachvollziehbar, jeder Control zitierbar. Das Framework ist frei nutzbar, offen für Beiträge und frei erweiterbar.

Podcast- / Interview-Intro

Wombat ist ein quelloffenes Framework, das Engineering- und Architekturteams einen anbieterneutralen Blick auf ihre Cloud-Workloads gibt. Alles ist in acht Säulen organisiert: Security, Reliability, Performance Efficiency, Cost Optimisation, Operational Excellence, Sustainability, Sovereign und Agentic.

Was Wombat auszeichnet, ist die Art, wie es entsteht: Jede Richtlinie, jede Scoring-Regel und jede Designentscheidung durchläuft einen öffentlichen RFC-Prozess auf GitHub — vollständig transparent, vollständig Community-getrieben. Kein Anbieter dahinter, kein Upselling, keine Blackbox. Alle können die Kriterien lesen, hinterfragen und verbessern.

Richtlinien zur Markennutzung.

So wird Wombat in redaktionellen Inhalten korrekt bezeichnet.

Bitte

Schreiben Sie den Projektnamen als Wombat, die Software als WOMBATpass und die CLI als wombat
Verwenden Sie die unveränderten Logodateien von dieser Seite
Nennen Sie als Quelle „Wombat, quelloffenes Framework für Cloud-Architektur“
Verlinken Sie auf www.wombat-gov.dev für Leserinnen und Leser, die mehr erfahren möchten

Bitte nicht

Logofarben oder -proportionen nicht verändern und keine Effekte hinzufügen
Keine Empfehlung oder offizielle Partnerschaft ohne schriftliche Genehmigung andeuten
Wombat-Materialien nicht so verwenden, dass Umfang oder Governance des Projekts falsch dargestellt werden
Den Namen nicht ohne Genehmigung in Produkt- oder Servicenamen verwenden
