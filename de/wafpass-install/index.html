Ihr erstes Ergebnis in 2 Minuten.

Folgen Sie den vier Schritten unten. Jeder Befehl ist so gestaltet, dass Sie schon beim ersten Versuch ein verlässliches, lesbares Ergebnis erhalten.

1

CLI installieren

WAFPass ist auf PyPI veröffentlicht als wafpass-core. Python 3.11+ wird empfohlen.

bash
$pip install wafpass-core
$wafpass --version
2

Controls herunterladen

Der WAF++-Controls-Katalog enthält die über 100 Regeln, mit denen WAFPass Ihren Code bewertet.

bash
$git clone https://github.com/WAF2p/framework.git controls-src
$cp -r controls-src/modules/controls/controls ./controls

Empfohlen: Klonen Sie das Controls-Repository. Alternativ: Laden Sie das Controls-ZIP von der WAFPass-Seite herunter und entpacken Sie es nach controls/.

3

Beispiel-Terraform-Datei speichern

Legen Sie eine minimale main.tfan. Dieses Beispiel lässt bewusst einen öffentlichen S3-Bucket offen, damit WAFPass etwas zu melden hat.

provider "aws" {
  region = "eu-central-1"
}

resource "aws_s3_bucket" "public" {
  bucket = "wafpp-first-check-demo"
}

resource "aws_s3_bucket_public_access_block" "public" {
  bucket                  = aws_s3_bucket.public.id
  block_public_acls       = false
  block_public_policy     = false
  ignore_public_acls      = false
  restrict_public_buckets = false
}
4

Ersten Check ausführen

Richten Sie WAFPass auf das aktuelle Verzeichnis und geben Sie die JSON-Zusammenfassung aus.

bash
$wafpass check . --output json | jq '.summary'

Die Ausgabe sollte etwa so aussehen:

{
  "total_controls": 100,
  "passed": 98,
  "failed": 2,
  "pillars": {
    "security": { "passed": 18, "failed": 2 }
  }
}
98 bestanden: Ressourcen haben den Control erfüllt
2 fehlgeschlagen: Ressourcen haben einen Control verletzt (hier der öffentliche S3-Bucket)
100 Controls: insgesamt geprüfte Regeln über 8 WAF++-Säulen

Das volle Dashboard lokal betreiben.

Das Monorepo WAF2p/pass liefert eine einheitliche docker-compose.ymlmit. Sie startet CLI, Server, Dashboard, PostgreSQL und Keycloak mit einem einzigen Befehl.

bash
$git clone https://github.com/WAF2p/pass.git
$cd pass
$cp .env.example .env
$# Edit .env, set POSTGRES_PASSWORD, WAFPASS_JWT_SECRET, etc.
$docker compose up -d

In CI / Pre-Commit einbinden.

Stoppen Sie nicht konforme Infrastruktur, bevor sie Ihren Main-Branch erreicht. WAFPass arbeitet ausschließlich mit den Dateien im Repository — CI-Checks sind schnell und brauchen keine Cloud-Secrets.

1

Pre-Commit-Hook installieren

Führen Sie das Installationsskript aus dem WAFPass-Repository einmal pro Klon aus. Danach wird jeder git commit automatisch geprüft.

bash
$bash hooks/install.sh # macOS / Linux / Git Bash
$.\hooks\install.ps1 # Windows PowerShell
2

WAFPass zu GitHub Actions hinzufügen

Fortgeschrittenes / manuelles Setup.

Installieren Sie nur die Komponenten, die Sie brauchen. Starten Sie mit der CLI für CI/CD und ergänzen Sie Server und Dashboard, wenn Sie Persistenz und visuelle Analyse benötigen.

1

wafpass-CLI installieren

Zentrale Prüf-Engine: IaC parsen, Controls bewerten, Berichte erzeugen.

Über PyPI (empfohlen)

bash
$pip install wafpass-core
$uv add wafpass-core # recommended for Python projects

Aus dem Quellcode

bash
$git clone https://github.com/WAF2p/pass.git
$cd pass
$uv pip install -e . # recommended
$pip install -e ".[pdf]" # with PDF report support

macOS (Apple M-series)

bash
$brew install git python uv
$git clone https://github.com/WAF2p/pass.git && cd pass
$uv pip install -e .
$wafpass --version # verify installation
2

wafpass-server installieren

FastAPI-Persistenzschicht: speichert Runs, Waiver, Secret-Findings und Audit-Ereignisse.

Über PyPI (empfohlen)

bash
$pip install wafpass-server
$uv add wafpass-server # recommended for Python projects

Konfigurieren & starten

bash
$cp .env.example .env # set DATABASE_URL and JWT secret
$alembic upgrade head # apply database migrations
$uvicorn wafpass_server.main:app --reload --port 8000

API-Dokumentation verfügbar unter http://localhost:8000/api/docs

3

wafpass-dashboard installieren

React-Web-Dashboard: über 22 Compliance-Ansichten, Nachweis-Export, RBAC.

bash
$git clone https://github.com/WAF2p/wafpass-dashboard.git
$cd wafpass-dashboard
$npm install
$cp .env.example .env.local # set VITE_API_URL
$npm run dev # dev server at http://localhost:5173

Häufige Probleme & Lösungen.

Schnelle Antworten, falls etwas beim ersten Versuch nicht klappt.

Controls nicht gefunden

Wenn wafpass check „controls directory not found“ meldet, zeigt die CLI automatisch eine Download-Anleitung an. Achten Sie darauf, dass der Ordner controls/ neben dem Verzeichnis liegt, in dem Sie scannen.

Port bereits belegt

Verwenden Sie einen anderen Port für Server oder Dashboard:

$uvicorn wafpass_server.main:app --port 8001
$npm run dev -- --port 5174
Fehler bei der Datenbankverbindung

Prüfen Sie, ob PostgreSQL läuft und Ihre DATABASE_URL korrekt ist:

$psql $DATABASE_URL -c "SELECT 1"
Docker-Build schlägt fehl

Beim Bauen aus dem Quellcode müssen alle drei Repositories nebeneinander im selben übergeordneten Verzeichnis geklont sein:

$ls -1
pass/
wafpass-server/
wafpass-dashboard/
