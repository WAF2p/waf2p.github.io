Rechtliches & Lizenzen.

WAF++ nutzt ein duales Lizenzmodell: Apache License 2.0 für Code und Creative Commons Attribution 4.0 (CC BY 4.0) für die Dokumentation. Dieses Modell ist CNCF-kompatibel und bereit für eine Stiftung.

Zwei Lizenzen, ein Framework.

Das duale Lizenzmodell hält WAF++ offen, kommerziell nutzbar und CNCF-tauglich — ohne Unklarheit darüber, was Sie damit tun dürfen.

Code → Apache 2.0

Gesamter Quellcode, Tooling und Framework-Komponenten — einschließlich WAFPass. Kommerzielle Nutzung, Änderung und Weitergabe sind ausdrücklich erlaubt. Inklusive Patentlizenz.

Dokumentation → CC BY 4.0

Alle schriftlichen Inhalte, Leitfäden, Säulendokumentation, Folien und Referenzmaterial. Frei teilen und bearbeiten — Namensnennung von WAF++ erforderlich.

Beiträge

Mit dem Einreichen eines Pull Requests stimmen Sie zu, dass Ihr Beitrag unter der jeweiligen Projektlizenz veröffentlicht wird (Apache 2.0 für Code, CC BY 4.0 für Dokumentation).

Apache License 2.0.

Der gesamte WAF++-Quellcode, WAFPass, Plugins und Tooling stehen unter der Apache License 2.0 — einer der freizügigsten und am weitesten verbreiteten Open-Source-Lizenzen.

Erlaubt

Kommerzielle Nutzung

Nutzen Sie WAFPass und den gesamten Framework-Code in kommerziellen Produkten, internen Tools und SaaS-Angeboten — ohne Lizenzgebühren oder Einschränkungen.

Erlaubt

Änderung & Weitergabe

Forken, ändern und verteilen Sie den Code frei. Geänderte Versionen dürfen Sie zu eigenen Bedingungen verbreiten, solange die ursprüngliche Lizenz erhalten bleibt.

Enthalten

Ausdrückliche Patentlizenz

Contributors gewähren eine ausdrückliche, gebührenfreie Patentlizenz für alle Patente, die ihre Beiträge betreffen — zum Schutz der nachgelagerten Nutzer.

Nicht erforderlich

Keine Copyleft-Pflichten

Keine Pflicht, eigenen Code offenzulegen, wenn Sie WAF++-Komponenten nutzen. Proprietäre Integrationen sind uneingeschränkt erlaubt.

Creative Commons BY 4.0.

Die gesamte WAF++-Dokumentation, Säulenleitfäden, Folien, Referenzmaterial und schriftlichen Inhalte werden unter CC BY 4.0 veröffentlicht.

Was Sie dürfen

  • Teilen — das Material in jedem Medium und Format kopieren und weiterverbreiten
  • Bearbeiten — das Material remixen, verändern und darauf aufbauen
  • Kommerzielle Nutzung — die Dokumentation für jeden Zweck nutzen, auch kommerziell

Eine Bedingung

  • Namensnennung erforderlich — Sie müssen WAF++ angemessen nennen, einen Link zur Lizenz angeben und kenntlich machen, ob Änderungen vorgenommen wurden.
Beispiel: „Basierend auf der WAF++-Dokumentation, CC BY 4.0 — waf2p.dev“

Haftungsausschluss & Beiträge.

Wichtiger rechtlicher Kontext für die Nutzung von und Mitwirkung an WAF++.

Haftungsausschluss

WAF++ wird „wie besehen“ ohne ausdrückliche oder stillschweigende Gewährleistung bereitgestellt. Die Nutzung des Frameworks erfolgt auf eigenes Risiko.

Das Framework ersetzt keine Rechtsberatung, formale Zertifizierung oder Compliance-Prüfung. Es bietet Orientierung, Bewertungsmodelle und nachvollziehbare Kriterien.

Beiträge & Compliance

Mit dem Einreichen eines Pull Requests stimmen Sie zu, dass Ihr Beitrag unter der jeweils geltenden Projektlizenz veröffentlicht wird:

  • Code-Beiträge → Apache 2.0
  • Dokumentationsbeiträge → CC BY 4.0
