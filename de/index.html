Erstes Ergebnis in 2 Minuten

Drei Schritte zu Ihrem ersten Scan.

01
CLI installieren

Ein PyPI-Paket liefert die Static-Analysis-Engine.

pip install wafpass-core
02
Ein Kommando ausführen

Zeigen Sie WAFPass auf Ihren Terraform-Ordner und erhalten Sie eine JSON-Zusammenfassung.

wafpass check . --output json | jq '.summary'
03
Sehen Sie, was falsch ist

Eine klare Pass/Fail-Anzahl und Befunde pro Control zeigen genau, was behoben werden muss.

81 passed · 2 failed

So sieht ein erster Befund aus

WAFPass markiert einen öffentlichen S3-Bucket und zeigt das genaue Control sowie die Behebung.

FAIL SEC-S3-001

S3-Bucket-Public-Access-Block ist deaktiviert. Öffentliche Buckets setzen Daten dem Internet aus.

Fix-Snippet
resource "aws_s3_bucket_public_access_block" "public" {
  bucket                  = aws_s3_bucket.public.id
  block_public_acls       = true
  block_public_policy     = true
  ignore_public_acls      = true
  restrict_public_buckets = true
}
