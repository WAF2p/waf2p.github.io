Compliance in Ihrer Pipeline.

Fügen Sie WOMBATpass zu jedem Workflow hinzu. Scannen Sie Terraform, Bicep, CDK oder Pulumi bei jedem Pull Request und Push und senden Sie das vollständige Ergebnis an Ihren WOMBATpass-Server — für Dashboards, Lückenanalysen und Audit-Nachweise.

Ein Schritt. Volle Transparenz.

Die Action übernimmt CLI-Installation, Scan, Ergebnis-Upload und Policy-Durchsetzung, damit sich Ihr Team aufs Ausliefern konzentrieren kann.

CLI automatisch installieren

Installiert automatisch das neueste wafpass-core von PyPI — oder nutzen Sie eine eigene pip-Quelle bzw. ein vorinstalliertes Binary.

Multi-IaC-Scan

Scannen Sie Terraform-, Bicep-, CDK- oder Pulumi-Dateien in einem Schritt. Unterstützt mehrere Pfade und Terraform-Plan-JSON für eine Änderungsübersicht.

An den Server senden

Lädt das vollständige wafpass-result.json an POST /api/v1/runs hoch, damit Dashboards und Evidenzpakete aktuell bleiben.

Policy-Gates

Konfigurierbare fail_on -Policies von never bis critical. Der Schritt schlägt erst fehl, nachdem das Ergebnis sicher auf dem Server gespeichert ist.

Flexible Authentifizierung

Nutzen Sie ein Bearer-Token für interaktive Nutzer oder einen Ingest-API-Key für headless CI/CD-Läufe. Beide werden sicher an den Server weitergegeben.

CI/CD-Metadaten

Markiert Runs als is_cicd: true mit triggered_by: github-actions und übergibt Branch, Commit-SHA, Projekt und Stage automatisch.

In jeden Workflow einbauen.

Repo auschecken, Action ausführen und Compliance-Ergebnisse dort sichtbar machen, wo Ihr Team ohnehin arbeitet.

.github/workflows/wafpass.yml
{% raw %}
name: WOMBATpass Scan

on:
  push:
    branches: [main, develop]
  pull_request:

jobs:
  wafpass:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Run WOMBATpass
        uses: WAF2p/wafpass-action@v0.1.1
        with:
          server_url: ${{ vars.WAFPASS_SERVER_URL }}
          api_key: ${{ secrets.WAFPASS_API_KEY }}
          scan_path: ./infra
          iac_framework: terraform
          project: ${{ github.repository }}
          stage: ${{ github.ref_name == 'main' && 'prod' || 'dev' }}
          fail_on: high
          upload_source: true
{% endraw %}
