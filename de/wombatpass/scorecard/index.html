Mach deinen WOMBATpass-Score teilbar.

Füge eine wombat-result.json ein und erhalte eine 1200×630 Score-Karte, ein README-Badge und Copy-Paste-Snippets. Alles wird im Browser gerendert — die Datei verlässt deinen Rechner nicht.

  • 1200×630 Karte
  • PNG + SVG
  • 8 Säulen-Balken
  • README-Badge

1. Ergebnis einfügen

Starte die CLI, speichere das JSON und füge es hier ein.

wombat check . --output json > wombat-result.json

Noch keine CLI? WOMBATpass installieren.

Welches JSON brauche ich?

Nutze die JSON-Ausgabe eines WOMBATpass-Laufs. Die Karte liest score, pillar_scores, project, branch, git_sha, iac_framework und stage. Sie versteht auch das Summary-Format (total_controls, passed, failed, pillars) und Validierungs-Envelopes mit verschachteltem result. Ältere wafpass check-Ausgaben funktionieren ebenfalls.
