Um passo. Visibilidade total.

A action trata da instalação da CLI, da verificação, do envio dos resultados e da aplicação das políticas, para que a sua equipe se possa concentrar em entregar.

Instalação automática da CLI

Instala automaticamente a versão mais recente do wafpass-core a partir do PyPI, ou use uma fonte pip personalizada ou um binário pré-instalado.

Verificação multi-IaC

Verifique ficheiros Terraform, Bicep, CDK ou Pulumi num único passo. Suporta vários caminhos e o JSON do plano Terraform para uma visão das alterações.

Envio para o servidor

Envia o wafpass-result.json completo para POST /api/v1/runs , para que os painéis e os pacotes de evidências se mantenham atualizados.

Gates de políticas

Políticas fail_on configuráveis, de never a critical. O passo só falha depois de o resultado estar guardado em segurança no servidor.

Autenticação flexível

Use um token Bearer para utilizadores interativos ou uma chave de API de ingestão para execuções de CI/CD sem interface. Ambos são reencaminhados com segurança para o servidor.

Metadados de CI/CD

Marca as execuções como is_cicd: true com triggered_by: github-actions e passa automaticamente o branch, o SHA do commit, o projeto e o stage.

Adicione-a a qualquer workflow.

Faça checkout do repositório, execute a action e mostre os resultados de conformidade onde a sua equipe já trabalha.

.github/workflows/wafpass.yml
{% raw %}
name: WOMBATpass Scan

on:
  push:
    branches: [main, develop]
  pull_request:

jobs:
  wafpass:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Run WOMBATpass
        uses: WAF2p/wafpass-action@v0.1.1
        with:
          server_url: ${{ vars.WAFPASS_SERVER_URL }}
          api_key: ${{ secrets.WAFPASS_API_KEY }}
          scan_path: ./infra
          iac_framework: terraform
          project: ${{ github.repository }}
          stage: ${{ github.ref_name == 'main' && 'prod' || 'dev' }}
          fail_on: high
          upload_source: true
{% endraw %}
