Texto institucional aprovado.

Use os textos a seguir ao descrever o Wombat em artigos, podcasts ou apresentações.

Curto (1 frase)

O Wombat é um framework open source e neutro em relação a fornecedores para avaliar e melhorar a qualidade de workloads em nuvem em 8 pilares: Security, Reliability, Performance Efficiency, Cost Optimisation, Operational Excellence, Sustainability, Sovereign e Agentic.

Redes sociais / formato curto (≤ 280 caracteres)

O Wombat é um framework open source e neutro para a qualidade de arquiteturas em nuvem: 8 pilares, pontuação transparente, governança comunitária via RFCs públicas. Docs sob CC BY 4.0, código sob Apache 2.0. www.wombat-gov.dev

Padrão (2–3 frases)

O Wombat é um framework open source movido pela comunidade para avaliar e melhorar a qualidade de workloads em nuvem. Ele abrange 8 pilares — Security, Reliability, Performance Efficiency, Cost Optimisation, Operational Excellence, Sustainability, Sovereign e Agentic — com um modelo de pontuação transparente chamado PASS.

Ao contrário dos frameworks proprietários de fornecedores, o Wombat é governado abertamente via RFCs no GitHub Discussions, tornando cada decisão rastreável e cada controle citável. O framework é livre para usar, contribuir e expandir.

Introdução para podcast / entrevista

Wombat (anteriormente conhecido como WAF++) é um framework open source que oferece às equipes de engenharia e arquitetura uma lente neutra para avaliar workloads em nuvem. Tudo é organizado em oito pilares: Security, Reliability, Performance Efficiency, Cost Optimisation, Operational Excellence, Sustainability, Sovereign e Agentic.

O que diferencia o Wombat é a forma como ele é construído: cada diretriz, regra de pontuação e decisão de design passa por um processo de RFC público no GitHub, totalmente transparente e totalmente movido pela comunidade. Não há fornecedor por trás, nem upsell, nem caixa-preta. Qualquer pessoa pode ler os critérios, questioná-los e melhorá-los.

Diretrizes de uso da marca.

Como se referir corretamente ao Wombat em conteúdo editorial.

Faça

Escreva o nome do projeto como Wombat, o software como WOMBATpass e a CLI como wombat
Use os arquivos de logo sem alterações desta página
Credite como “Wombat, framework open source de arquitetura em nuvem”
Inclua um link para www.wombat-gov.dev para leitores que queiram saber mais

Não faça

Não altere cores ou proporções do logo nem adicione efeitos
Não sugira endosso ou parceria oficial sem permissão por escrito
Não use os materiais do Wombat de forma que distorça o escopo ou a governança do projeto
Não use o nome em nomes de produtos ou serviços sem permissão
