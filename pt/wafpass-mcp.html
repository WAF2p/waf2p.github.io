Os seus dados, em qualquer host MCP.

A Wombat MCP Bridge expõe a API REST do WOMBATpass como ferramentas Model Context Protocol para assistentes de IA. Peça ao Claude para listar execuções, inspecionar constatações ou explorar dados de conformidade, tudo através da mesma sessão SSO e das mesmas permissões por função em que já confia.

Uma ponte segura, não um segundo sistema de autenticação.

A ponte reutiliza a identidade, as permissões e as trilhas de auditoria do WOMBATpass. Valida, faz proxy e filtra, sem nunca guardar segredos da nuvem nem palavras-passe do IdP.

Agnóstica ao IdP

Sem integração direta com Keycloak, Entra ou Okta. A ponte confia nos tokens emitidos pelo wafpass-server, que já trata os fluxos OIDC e SAML.

Introspeção de tokens

Cada nova ligação SSE é validada contra GET /auth/me. Deteção imediata de revogações e sem necessidade de partilhar segredos JWT.

Ferramentas com privilégio mínimo

tools/list é filtrado pela função do utilizador autenticado. Os endpoints exclusivos de administradores ficam invisíveis para os engenheiros, e a autorização por linha aplica-se a cada chamada ao backend.

Propagação de contexto

O cabeçalho original Authorization: Bearer é reencaminhado para o WOMBATpass em cada pedido, preservando a identidade do utilizador e a atribuição na auditoria.

Gerado a partir de OpenAPI

No arranque, a ponte obtém /openapi.json e regista as operações seguras como ferramentas MCP tipadas, com argumentos validados pelo Pydantic.

stdio ou SSE

Execute a ponte como processo stdio local para o Claude Desktop ou exponha-a por HTTP/SSE para hosts MCP remotos e clientes no browser.

Ligue o Claude Desktop em minutos.

Instale a ponte, inicie sessão uma vez e aponte o Claude Desktop para o comando stdio. Sem certificados, sem portas abertas, sem autenticação adicional.

1. Instalar e configurar 
git clone https://github.com/WAF2p/wafpass-mcp.git
cd wafpass-mcp
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"

wafpass-mcp-configure
# Enter WOMBATpass API URL, username and password
2. Configuração do Claude Desktop (stdio) 
{
  "mcpServers": {
    "wafpass": {
      "command": "/path/to/wafpass-mcp/.venv/bin/wafpass-mcp-stdio"
    }
  }
}
3. Docker Compose (alternativa) 
# From the Wombat repository root
docker compose up -d wafpass-mcp
docker compose logs -f wafpass-mcp

# SSE endpoint: http://localhost:3001/sse
# Override WAFPASS_TOKEN_MODE or WAFPASS_JWT_SECRET in .env

Como a ponte se encaixa.

O utilizador autentica-se através do IdP a montante, troca tokens com o WOMBATpass e leva o mesmo token Bearer para o host MCP. A ponte reencaminha os pedidos e filtra as ferramentas por função.
