Comece com o quickstart da CLI de 2 minutos. Troque de aba quando estiver pronto para o painel, a CI ou a configuração manual.

Obtenha seu primeiro resultado em 2 minutos.

Siga os quatro passos abaixo. Cada comando foi pensado para dar um resultado garantido e legível já na primeira tentativa.

1

Instalar a CLI

O WAFPass está publicado no PyPI como wafpass-core. Recomenda-se Python 3.11+.

bash
$pip install wafpass-core
$wafpass --version
2

Baixar os controles

O catálogo de controles do WAF++ contém as mais de 100 regras que o WAFPass usa para avaliar seu código.

bash
$git clone https://github.com/WAF2p/framework.git controls-src
$cp -r controls-src/modules/controls/controls ./controls

Recomendado: clone o repositório de controles. Alternativa: baixe o zip de controles na página do WAFPass e extraia-o em controls/.

3

Salvar um arquivo Terraform de exemplo

Crie um main.tfmínimo. Este exemplo deixa de propósito um bucket S3 público para que o WAFPass tenha algo a apontar.

provider "aws" {
  region = "eu-central-1"
}

resource "aws_s3_bucket" "public" {
  bucket = "wafpp-first-check-demo"
}

resource "aws_s3_bucket_public_access_block" "public" {
  bucket                  = aws_s3_bucket.public.id
  block_public_acls       = false
  block_public_policy     = false
  ignore_public_acls      = false
  restrict_public_buckets = false
}
4

Executar sua primeira verificação

Aponte o WAFPass para o diretório atual e imprima o resumo em JSON.

bash
$wafpass check . --output json | jq '.summary'

Você deve ver uma saída como esta:

{
  "total_controls": 100,
  "passed": 98,
  "failed": 2,
  "pillars": {
    "security": { "passed": 18, "failed": 2 }
  }
}
98 aprovados: recursos que atenderam ao controle
2 com falha: recursos que violaram um controle (aqui, o bucket S3 público)
100 controles: total de regras avaliadas nos 8 pilares do WAF++

Rode o painel completo localmente.

O monorepo WAF2p/pass traz um docker-compose.ymlunificado. Ele sobe a CLI, o servidor, o painel, o PostgreSQL e o Keycloak com um único comando.

bash
$git clone https://github.com/WAF2p/pass.git
$cd pass
$cp .env.example .env
$# Edit .env, set POSTGRES_PASSWORD, WAFPASS_JWT_SECRET, etc.
$docker compose up -d

Adicionar à CI / pre-commit.

Bloqueie infraestrutura não conforme antes que ela chegue à sua branch principal. O WAFPass trabalha só com os arquivos do repositório, então as verificações de CI são rápidas e não exigem segredos de nuvem.

1

Instalar o hook de pre-commit

Execute o script de instalação do repositório do WAFPass uma vez por clone. Depois disso, cada git commit é verificado automaticamente.

bash
$bash hooks/install.sh # macOS / Linux / Git Bash
$.\hooks\install.ps1 # Windows PowerShell
2

Adicionar o WAFPass ao GitHub Actions

Use a GitHub Action oficial do WAFPass para reprovar pull requests que introduzam erros de configuração. Funciona com repositórios públicos e privados.

Configurar o WAFPass Action

Configuração avançada / manual.

Instale só os componentes de que precisa. Comece pela CLI para CI/CD e adicione servidor e painel quando precisar de persistência e exploração visual.

1

Instalar a CLI wafpass

Motor de avaliação principal: analisa IaC, avalia controles e gera relatórios.

Pelo PyPI (recomendado)

bash
$pip install wafpass-core
$uv add wafpass-core # recommended for Python projects

A partir do código-fonte

bash
$git clone https://github.com/WAF2p/pass.git
$cd pass
$uv pip install -e . # recommended
$pip install -e ".[pdf]" # with PDF report support

macOS (Apple M-series)

bash
$brew install git python uv
$git clone https://github.com/WAF2p/pass.git && cd pass
$uv pip install -e .
$wafpass --version # verify installation
2

Instalar o wafpass-server

Camada de persistência com FastAPI: armazena execuções, exceções, segredos encontrados e eventos de auditoria.

Pelo PyPI (recomendado)

bash
$pip install wafpass-server
$uv add wafpass-server # recommended for Python projects

Configurar e iniciar

bash
$cp .env.example .env # set DATABASE_URL and JWT secret
$alembic upgrade head # apply database migrations
$uvicorn wafpass_server.main:app --reload --port 8000

Documentação da API disponível em http://localhost:8000/api/docs

3

Instalar o wafpass-dashboard

Painel web em React: mais de 22 visões de conformidade, exportação de evidências, RBAC.

bash
$git clone https://github.com/WAF2p/wafpass-dashboard.git
$cd wafpass-dashboard
$npm install
$cp .env.example .env.local # set VITE_API_URL
$npm run dev # dev server at http://localhost:5173

Problemas comuns e soluções.

Respostas rápidas se algo não funcionar na primeira tentativa.

Controles não encontrados

Se wafpass check informar "controls directory not found", a CLI exibe automaticamente as instruções de download. Verifique se a pasta controls/ está ao lado do local onde você executa as varreduras.

Porta já em uso

Use outra porta para o servidor ou o painel:

$uvicorn wafpass_server.main:app --port 8001
$npm run dev -- --port 5174
Erros de conexão com o banco de dados

Verifique se o PostgreSQL está rodando e se sua DATABASE_URL está correta:

$psql $DATABASE_URL -c "SELECT 1"
Falha no build do Docker

Ao compilar a partir do código-fonte, os três repositórios devem estar clonados lado a lado no mesmo diretório pai:

$ls -1
pass/
wafpass-server/
wafpass-dashboard/
