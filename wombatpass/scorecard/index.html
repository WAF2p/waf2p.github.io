Make your WOMBATpass score shareable.

Drop in a wombat-result.json and get a 1200×630 score card, a README badge and copy-paste snippets. Everything renders in your browser — the file never leaves your machine.

  • 1200×630 card
  • PNG + SVG
  • 8 pillar bars
  • README badge

1. Paste your result

Run the CLI and save the JSON, then paste it here.

wombat check . --output json > wombat-result.json

Need the CLI? Install WOMBATpass.

What JSON do I need?

Use the JSON output of a WOMBATpass run. The card reads score, pillar_scores, project, branch, git_sha, iac_framework and stage. It also understands the summary shape (total_controls, passed, failed, pillars) and validation envelopes with a nested result. Older wafpass check output works too.
