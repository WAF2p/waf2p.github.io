Krijg je eerste resultaat in 2 minuten

Volg de vier stappen hieronder. Elk commando is ontworpen om je gegarandeerd een leesbaar resultaat te geven bij je eerste poging.

1

Installeer de CLI

WAFPass wordt gepubliceerd op PyPI als wafpass-core. Python 3.11+ wordt aanbevolen.

bash
$ pip install wafpass-core
$ wafpass --version
2

Download de controls

De WAF++ controls-catalogus bevat de 83+ regels die WAFPass gebruikt om je code te evalueren.

bash
$ git clone https://github.com/WAF2p/framework.git controls-src
$ cp -r controls-src/modules/controls/controls ./controls

Aanbevolen: clone de controls-repository. Alternatief: download de controls-zip van de WAFPass-pagina en pak deze uit in controls/.

3

Bewaar een voorbeeld-Terraform-bestand

Maak een minimaal main.tf. Dit voorbeeld laat expres een publieke S3-bucket staan, zodat WAFPass iets heeft om te markeren.

provider "aws" {
  region = "eu-central-1"
}

resource "aws_s3_bucket" "public" {
  bucket = "wafpp-first-check-demo"
}

resource "aws_s3_bucket_public_access_block" "public" {
  bucket                  = aws_s3_bucket.public.id
  block_public_acls       = false
  block_public_policy     = false
  ignore_public_acls      = false
  restrict_public_buckets = false
}
4

Voer je eerste check uit

Richt WAFPass op de huidige map en print de JSON-samenvatting.

bash
$ wafpass check . --output json | jq '.summary'

Je ziet output zoals deze:

{
  "total_controls": 83,
  "passed": 81,
  "failed": 2,
  "pillars": {
    "security": { "passed": 18, "failed": 2 }
  }
}
81 passed — resources voldeden aan de control
2 failed — resources schenden een control (hier, de publieke S3-bucket)
83 controls — totaal aantal regels geëvalueerd over 8 WAF++-pijlers

Draai het volledige dashboard lokaal

De WAF2p/pass-monorepo levert een unified docker-compose.yml. Het start de CLI, server, dashboard, PostgreSQL en Keycloak in één commando.

bash
$ git clone https://github.com/WAF2p/pass.git
$ cd pass
$ cp .env.example .env
$ # Edit .env — set POSTGRES_PASSWORD, WAFPASS_JWT_SECRET, etc.
$ docker compose up -d

Voeg toe aan CI / pre-commit

Blokkeer niet-conforme infrastructuur voordat deze je main branch bereikt. WAFPass draait volledig op de bestanden in de repo, dus CI-checks zijn snel en hebben geen cloud-secrets nodig.

1

Installeer de pre-commit hook

Voer het installatiescript van de WAFPass-repository één keer per clone uit. Daarna wordt elke git commit automatisch gecontroleerd.

bash
$ bash hooks/install.sh # macOS / Linux / Git Bash
$ .\hooks\install.ps1 # Windows PowerShell
2

Voeg WAFPass toe aan GitHub Actions

Gebruik de officiële WAFPass GitHub Action om pull requests die misconfiguraties introduceren te laten falen. Werkt met publieke en private repositories.

Geavanceerde / handmatige setup

Installeer alleen de componenten die je nodig hebt. Begin met de CLI voor CI/CD, voeg daarna de server en het dashboard toe wanneer je persistentie en visuele exploratie nodig hebt.

1
Installeer wafpass CLI

Core evaluation engine — parse IaC, evalueer controls, genereer rapporten

Van PyPI (aanbevolen)

bash
$ pip install wafpass-core
$ uv add wafpass-core # recommended for Python projects

Van bron

bash
$ git clone https://github.com/WAF2p/pass.git
$ cd pass
$ uv pip install -e . # recommended
$ pip install -e ".[pdf]" # with PDF report support

macOS (Apple M-series)

bash
$ brew install git python uv
$ git clone https://github.com/WAF2p/pass.git && cd pass
$ uv pip install -e .
$ wafpass --version # verify installation
2
Installeer wafpass-server

FastAPI persistence layer — slaat runs, ontheffingen, secrets-bevindingen en audit-events op

Van PyPI (aanbevolen)

bash
$ pip install wafpass-server
$ uv add wafpass-server # recommended for Python projects

Configureer & start

bash
$ cp .env.example .env # set DATABASE_URL and JWT secret
$ alembic upgrade head # apply database migrations
$ uvicorn wafpass_server.main:app --reload --port 8000

API-docs beschikbaar op http://localhost:8000/api/docs

3
Installeer wafpass-dashboard

React web dashboard — 22+ compliance-views, evidence-export, RBAC

bash
$ git clone https://github.com/WAF2p/wafpass-dashboard.git
$ cd wafpass-dashboard
$ npm install
$ cp .env.example .env.local # set VITE_API_URL
$ npm run dev # dev server at http://localhost:5173
PROBLEMEN

Veelvoorkomende problemen & oplossingen.

Snelle antwoorden als iets niet meteen werkt.

Controls niet gevonden

Als wafpass check "controls directory not found" rapporteert, toont de CLI automatisch download-instructies. Zorg dat de controls/-map naast de plek staat waar je scans uitvoert.

Poort al in gebruik

Gebruik een andere poort voor de server of het dashboard:

$ uvicorn wafpass_server.main:app --port 8001
$ npm run dev -- --port 5174
Database-verbindingsfouten

Controleer dat PostgreSQL draait en dat je DATABASE_URL klopt:

$ psql $DATABASE_URL -c "SELECT 1"
Docker-build mislukt

Zorg dat alle drie de repositories naast elkaar in dezelfde parent-directory zijn gekloond wanneer je vanuit bron bouwt:

$ ls -1
pass/
wafpass-server/
wafpass-dashboard/
