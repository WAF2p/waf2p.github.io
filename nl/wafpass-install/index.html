Eén duidelijk pad voor elke use case.

Begin met de CLI-quickstart van 2 minuten. Wissel van tab zodra je klaar bent voor het dashboard, CI of een handmatige setup.

Je eerste resultaat in 2 minuten.

Volg de vier stappen hieronder. Elk commando is zo opgezet dat je bij de eerste poging een gegarandeerd, leesbaar resultaat krijgt.

1

De CLI installeren

WOMBATpass is op PyPI gepubliceerd als wafpass-core. Python 3.11+ wordt aanbevolen.

bash
$pip install wafpass-core
$wombat --version
2

De controls downloaden

De Wombat-controlcatalogus bevat de 100+ regels waarmee WOMBATpass je code beoordeelt.

bash
$git clone https://github.com/WAF2p/framework.git controls-src
$cp -r controls-src/modules/controls/controls ./controls

Aanbevolen: clone de controls-repository. Alternatief: download de controls-zip van de WOMBATpass-pagina en pak hem uit naar controls/.

3

Een voorbeeldbestand in Terraform opslaan

Maak een minimale main.tfaan. Dit voorbeeld laat bewust een publieke S3-bucket open, zodat WOMBATpass iets te melden heeft.

provider "aws" {
  region = "eu-central-1"
}

resource "aws_s3_bucket" "public" {
  bucket = "wafpp-first-check-demo"
}

resource "aws_s3_bucket_public_access_block" "public" {
  bucket                  = aws_s3_bucket.public.id
  block_public_acls       = false
  block_public_policy     = false
  ignore_public_acls      = false
  restrict_public_buckets = false
}
4

Je eerste check uitvoeren

Richt WOMBATpass op de huidige map en toon de JSON-samenvatting.

bash
$wombat check . --output json | jq '.summary'

Je zou output als deze moeten zien:

{
  "total_controls": 100,
  "passed": 98,
  "failed": 2,
  "pillars": {
    "security": { "passed": 18, "failed": 2 }
  }
}
98 geslaagd: resources voldeden aan de control
2 gefaald: resources schonden een control (hier de publieke S3-bucket)
100 controls: totaal aantal geëvalueerde regels over 8 Wombat-pijlers

De monorepo WAF2p/pass levert een uniforme docker-compose.ymlmee. Die start CLI, server, dashboard, PostgreSQL en Keycloak met één commando.

$cd pass
$cp .env.example .env

Toevoegen aan CI / pre-commit.

Houd niet-conforme infrastructuur tegen voordat die je main-branch bereikt. WOMBATpass werkt alleen met de bestanden in de repository, dus CI-checks zijn snel en hebben geen cloudsecrets nodig.

1

De pre-commit-hook installeren

Voer het installatiescript uit de WOMBATpass-repository één keer per clone uit. Daarna wordt elke git commit automatisch gecontroleerd.

bash
$bash hooks/install.sh # macOS / Linux / Git Bash
$.\hooks\install.ps1 # Windows PowerShell
2

WOMBATpass toevoegen aan GitHub Actions

Gebruik de officiële WOMBATpass GitHub Action om pull requests met misconfiguraties te laten falen. Werkt met publieke en private repositories.

WOMBATpass Action instellen

Geavanceerde / handmatige setup.

Installeer alleen de componenten die je nodig hebt. Begin met de CLI voor CI/CD en voeg server en dashboard toe wanneer je persistentie en visuele analyse nodig hebt.

1

wafpass-CLI installeren

Centrale evaluatie-engine: IaC parsen, controls evalueren, rapporten genereren.

Via PyPI (aanbevolen)

bash
$pip install wafpass-core
$uv add wafpass-core # recommended for Python projects

Vanuit de broncode

bash
$git clone https://github.com/WAF2p/pass.git
$cd pass
$uv pip install -e . # recommended
$pip install -e ".[pdf]" # with PDF report support

macOS (Apple M-series)

bash
$brew install git python uv
$git clone https://github.com/WAF2p/pass.git && cd pass
$uv pip install -e .
$wombat --version # verify installation
2

wafpass-server installeren

FastAPI-persistentielaag: slaat runs, waivers, gevonden secrets en audit-events op.

Via PyPI (aanbevolen)

bash
$pip install wafpass-server
$uv add wafpass-server # recommended for Python projects

Configureren & starten

bash
$cp .env.example .env # set DATABASE_URL and JWT secret
$alembic upgrade head # apply database migrations
$uvicorn wafpass_server.main:app --reload --port 8000

API-documentatie beschikbaar op http://localhost:8000/api/docs

3

wafpass-dashboard installeren

React-webdashboard: 22+ complianceweergaven, bewijsexport, RBAC.

bash
$git clone https://github.com/WAF2p/wafpass-dashboard.git
$cd wafpass-dashboard
$npm install
$cp .env.example .env.local # set VITE_API_URL
$npm run dev # dev server at http://localhost:5173

Veelvoorkomende problemen & oplossingen.

Snelle antwoorden als iets niet meteen werkt.

Controls niet gevonden

Als wombat check "controls directory not found" meldt, toont de CLI automatisch downloadinstructies. Zorg dat de map controls/ naast de plek staat waar je scant.

Poort al in gebruik

Gebruik een andere poort voor de server of het dashboard:

$uvicorn wafpass_server.main:app --port 8001
$npm run dev -- --port 5174
Fouten bij de databaseverbinding

Controleer of PostgreSQL draait en of je DATABASE_URL klopt:

$psql $DATABASE_URL -c "SELECT 1"
Docker-build mislukt

Bij een build vanuit de broncode moeten alle drie de repositories naast elkaar in dezelfde bovenliggende map gecloned zijn:

$ls -1
pass/
wafpass-server/
wafpass-dashboard/
