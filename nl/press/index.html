Goedgekeurde standaardtekst.

Gebruik de volgende teksten wanneer je WAF++ beschrijft in artikelen, podcasts of presentaties.

Kort (1 zin)

WAF++ is een open-source, leveranciersneutraal framework om de kwaliteit van cloudworkloads te beoordelen en te verbeteren over 8 pijlers: Security, Reliability, Performance Efficiency, Cost Optimisation, Operational Excellence, Sustainability, Sovereign en Agentic.

Social / kort (≤ 280 tekens)

WAF++ is een open-source, leveranciersneutraal framework voor de kwaliteit van cloudarchitectuur — 8 pijlers, transparante scoring, community-governance via openbare RFC's. Docs onder CC BY 4.0, code onder Apache 2.0. waf2p.dev

Standaard (2–3 zinnen)

WAF++ (Well-Architected Framework Plus Plus) is een open-source, door de community gedreven framework om de kwaliteit van cloudworkloads te beoordelen en te verbeteren. Het omvat 8 pijlers — Security, Reliability, Performance Efficiency, Cost Optimisation, Operational Excellence, Sustainability, Sovereign en Agentic — met een transparant scoringmodel genaamd PASS.

Anders dan propriëtaire frameworks van leveranciers wordt WAF++ openlijk bestuurd via RFC's in GitHub Discussions, waardoor elk besluit herleidbaar en elke control citeerbaar is. Het framework is vrij te gebruiken, open voor bijdragen en om op voort te bouwen.

Intro voor podcast / interview

WAF++ — uitgesproken als ‘waf plus plus’ — is een open-source framework dat engineering- en architectuurteams een leveranciersneutrale blik geeft om cloudworkloads te beoordelen. Alles is georganiseerd in acht pijlers: Security, Reliability, Performance Efficiency, Cost Optimisation, Operational Excellence, Sustainability, Sovereign en Agentic.

Wat WAF++ onderscheidt, is hoe het gebouwd wordt: elke richtlijn, scoringregel en ontwerpbeslissing doorloopt een openbaar RFC-proces op GitHub — volledig transparant, volledig door de community gedreven. Geen leverancier erachter, geen upsell, geen black box. Iedereen kan de criteria lezen, ter discussie stellen en verbeteren.
