Een veilige bridge, geen tweede authenticatiesysteem.

De bridge hergebruikt identiteit, rechten en audittrails van WOMBATpass. Hij valideert, proxyt en filtert, en slaat nooit cloudsecrets of IdP-wachtwoorden op.

IdP-agnostisch

Geen directe integratie met Keycloak, Entra of Okta. De bridge vertrouwt tokens die zijn uitgegeven door wafpass-server, dat OIDC- en SAML-flows al afhandelt.

Token-introspectie

Elke nieuwe SSE-verbinding wordt gevalideerd via GET /auth/me. Directe detectie van intrekkingen en geen gedeelde JWT-secrets nodig.

Tools volgens least privilege

tools/list wordt gefilterd op de rol van de ingelogde gebruiker. Endpoints die alleen voor beheerders zijn, blijven onzichtbaar voor engineers, en autorisatie op rijniveau geldt bij elke backendaanroep.

Contextdoorgifte

De oorspronkelijke Authorization: Bearer -header wordt bij elk doorgestuurd verzoek naar WOMBATpass meegestuurd, zodat gebruikersidentiteit en audittoewijzing behouden blijven.

Gegenereerd uit OpenAPI

Bij het opstarten haalt de bridge /openapi.json op en registreert veilige operaties als getypeerde MCP-tools met door Pydantic gevalideerde argumenten.

stdio of SSE

Draai de bridge als lokaal stdio-proces voor Claude Desktop, of stel hem via HTTP/SSE beschikbaar voor externe MCP-hosts en browserclients.

Verbind Claude Desktop binnen enkele minuten.

Installeer de bridge, log één keer in en laat Claude Desktop naar het stdio-commando wijzen. Geen certificaten, geen open poorten, geen extra authenticatie.

1. Installeren en configureren 
git clone https://github.com/WAF2p/wafpass-mcp.git
cd wafpass-mcp
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"

wafpass-mcp-configure
# Enter WOMBATpass API URL, username and password
2. Claude Desktop-configuratie (stdio) 
{
  "mcpServers": {
    "wafpass": {
      "command": "/path/to/wafpass-mcp/.venv/bin/wafpass-mcp-stdio"
    }
  }
}
3. Docker Compose (alternatief) 
# From the Wombat repository root
docker compose up -d wafpass-mcp
docker compose logs -f wafpass-mcp

# SSE endpoint: http://localhost:3001/sse
# Override WAFPASS_TOKEN_MODE or WAFPASS_JWT_SECRET in .env

Hoe de bridge erin past.

De gebruiker authenticeert via de upstream-IdP, wisselt tokens uit met WOMBATpass en brengt hetzelfde Bearer-token naar de MCP-host. De bridge stuurt verzoeken door en filtert tools op rol.
