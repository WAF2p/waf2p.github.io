Wombat·Voorheen bekend als WAF++

De toekomst van cloudarchitectuur begint vandaag.

Wombat is een open, cloud-agnostisch framework dat je infrastructuur soeverein, veilig en auditklaar maakt — gekoppeld aan meer dan 100 controls verdeeld over 8 pijlers.

Het is nu tijd!

Jarenlang betekenden reviews van cloudarchitectuur lock-in bij één leverancier, schijnchecklists voor compliance of consultants met slidedecks. Wombat begint met een schone lei: een leveranciersneutraal framework, een statische CLI die je code leest, en bewijs dat iedereen kan verifiëren.

Ontdek hoe we je helpen groeien

Drie manieren waarop Wombat verandert hoe je cloudarchitectuur reviewt.

Soevereine cloudassessment

Voer dezelfde scan uit op AWS, Azure, GCP en Europese providers zoals OVH, Hetzner en STACKIT. Soevereiniteit is een volwaardige pijler, geen bijzaak.

Meer informatie

Beveiliging vóór de deployment

Hardcoded secrets, open netwerkpaden en ontbrekende toegangscontroles worden vóór de commit gesignaleerd. Statische analyse betekent: geen credentials en geen cloud-API-aanroepen.

Meer informatie

Auditklaar bewijs

Verzegel elke scan in een onveranderlijk, met hashes geverifieerd bewijspakket met een QR-code die auditors zelf kunnen controleren. Geen screenshots, geen slidedecks.

Van code naar bewijs.

{% include home-mascot.html variant="steps" text="Drie stappen. Geen inloggegevens." %}
Eerst

Schrijf Terraform

Bouw infrastructure as code zoals je dat al doet. Wombat blijft uit je workflow tot je het uitvoert.

Dan

Draai WOMBATpass

Een statische scan toetst elke resource aan de 100+ controls van het framework met wombat check . --output json. Geen credentials, geen API-aanroepen naar je cloudaccount.

Tot slot

Lever met bewijs

Exporteer de run als auditorklare pdf, of verzegel hem in een bewijspakket dat iedereen onafhankelijk kan verifiëren.
