Eerste resultaat in 2 minuten

Drie stappen naar je eerste scan.

01
Installeer de CLI

Eén PyPI-pakket geeft je de engine voor statische analyse.

pip install wafpass-core
02
Voer één commando uit

Richt WAFPass op je Terraform-map en krijg een JSON-samenvatting.

wafpass check . --output json | jq '.summary'
03
Zie wat er mis is

Een duidelijk pass/fail-overzicht en bevindingen per control vertellen je precies wat je moet oplossen.

81 passed · 2 failed

Zo ziet een eerste bevinding eruit

WAFPass markeert een publieke S3-bucket en toont de exacte control en de fix.

FAIL SEC-S3-001

Het public-access block van de S3-bucket is uitgeschakeld. Publieke buckets stellen data bloot aan het internet.

Fix-snippet
resource "aws_s3_bucket_public_access_block" "public" {
  bucket                  = aws_s3_bucket.public.id
  block_public_acls       = true
  block_public_policy     = true
  ignore_public_acls      = true
  restrict_public_buckets = true
}
