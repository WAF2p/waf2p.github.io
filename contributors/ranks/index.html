How points are earned.

Each signal has a fixed weight and a per-category cap. The cap keeps the rank from being a pure volume contest: a long review history and a focused control change both matter.

Offline-first, enriched when possible.

The weekly GitHub Action reads the committed contributor cache first. When a GITHUB_TOKEN is available it adds exact merged-PR, review and label counts from the GitHub GraphQL API. If the API is unavailable, the cached numbers are kept and the run still succeeds.

Signals that GitHub cannot see — conference talks, workshops and community sessions — are only ever added through a documented override in _data/ranks.yml. No contribution number is invented.

Privacy.

The rank system publishes the smallest useful surface: a public GitHub login and a rank. Nothing else.
