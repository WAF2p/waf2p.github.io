I tuoi dati, in qualsiasi host MCP.

WAF++ MCP Bridge espone l'API REST di WAFPass come strumenti Model Context Protocol per gli assistenti IA. Chiedi a Claude di elencare le esecuzioni, esaminare i risultati o esplorare i dati di conformità, tutto con la stessa sessione SSO e gli stessi permessi basati sui ruoli di cui già ti fidi.

Un bridge sicuro, non un secondo sistema di autenticazione.

Il bridge riutilizza identità, permessi e audit trail di WAFPass. Valida, fa da proxy e filtra, senza mai memorizzare segreti cloud o password dell'IdP.

Indipendente dall'IdP

Nessuna integrazione diretta con Keycloak, Entra o Okta. Il bridge si fida dei token emessi da wafpass-server, che gestisce già i flussi OIDC e SAML.

Introspezione dei token

Ogni nuova connessione SSE viene validata tramite GET /auth/me. Rilevamento immediato delle revoche e nessuna condivisione di segreti JWT.

Strumenti a privilegio minimo

tools/list viene filtrato in base al ruolo dell'utente autenticato. Gli endpoint riservati agli amministratori restano invisibili agli ingegneri e l'autorizzazione per riga si applica a ogni chiamata al backend.

Propagazione del contesto

L'header originale Authorization: Bearer viene inoltrato a WAFPass a ogni richiesta, preservando l'identità dell'utente e l'attribuzione negli audit.

Generato da OpenAPI

All'avvio il bridge recupera /openapi.json e registra le operazioni sicure come strumenti MCP tipizzati con argomenti validati da Pydantic.

stdio o SSE

Esegui il bridge come processo stdio locale per Claude Desktop oppure esponilo via HTTP/SSE per host MCP remoti e client basati su browser.

Collega Claude Desktop in pochi minuti.

Installa il bridge, accedi una volta e punta Claude Desktop al comando stdio. Nessun certificato, nessuna porta aperta, nessuna autenticazione aggiuntiva.

1. Installa e configura 
git clone https://github.com/WAF2p/wafpass-mcp.git
cd wafpass-mcp
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"

wafpass-mcp-configure
# Enter WAFpass API URL, username and password
2. Configurazione di Claude Desktop (stdio) 
{
  "mcpServers": {
    "wafpass": {
      "command": "/path/to/wafpass-mcp/.venv/bin/wafpass-mcp-stdio"
    }
  }
}
3. Docker Compose (alternativa) 
# From the WAF++ repository root
docker compose up -d wafpass-mcp
docker compose logs -f wafpass-mcp

# SSE endpoint: http://localhost:3001/sse
# Override WAFPASS_TOKEN_MODE or WAFPASS_JWT_SECRET in .env

Come si inserisce il bridge.

L'utente si autentica tramite l'IdP a monte, scambia i token con WAFPass e porta lo stesso token Bearer all'host MCP. Il bridge inoltra le richieste e filtra gli strumenti per ruolo.
