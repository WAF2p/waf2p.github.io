Primo risultato in 2 minuti

Tre passaggi per la tua prima scansione.

01
Installa la CLI

Un pacchetto PyPI ti fornisce il motore di analisi statica.

pip install wafpass-core
02
Esegui un comando

Punta WAFPass verso la tua cartella Terraform e ottieni un riepilogo JSON.

wafpass check . --output json | jq '.summary'
03
Vedi cosa c'è che non va

Un chiaro conteggio pass/fail e i risultati per controllo ti dicono esattamente cosa correggere.

81 passed · 2 failed

Cosa mostra una prima rilevazione

WAFPass segnala un bucket S3 pubblico e mostra il controllo esatto e la correzione.

FAIL SEC-S3-001

Il blocco degli accessi pubblici del bucket S3 è disabilitato. I bucket pubblici espongono i dati a internet.

Snippet di correzione
resource "aws_s3_bucket_public_access_block" "public" {
  bucket                  = aws_s3_bucket.public.id
  block_public_acls       = true
  block_public_policy     = true
  ignore_public_acls      = true
  restrict_public_buckets = true
}

Come funziona

Dal codice alla conformità in tre fasi.

Scrivi Terraform

Costruire infrastrutture-come-codifica il modo in cui si fa già. WAF++ rimane fuori dal flusso di lavoro.

L'analisi statica controlla ogni risorsa contro i controlli WAF++: nessuna credenziali cloud necessaria.

03
Rilascia in conformità

Esportare rapporti PDF, bloccare le violazioni in CI, e dimostrare la governance ai revisori.
