SCEGLI IL TUO PERCORSO

Un percorso chiaro per ogni esigenza.

Inizia con il quickstart CLI di 2 minuti. Passa alle altre schede quando sei pronto per la dashboard, CI o la configurazione manuale.

Ottieni il tuo primo risultato in 2 minuti

Segui i quattro passaggi qui sotto. Ogni comando è pensato per darti un risultato leggibile e garantito al primo tentativo.

1

Installa la CLI

WAFPass è pubblicato su PyPI come wafpass-core. Si consiglia Python 3.11+.

bash
$ pip install wafpass-core
$ wafpass --version
2

Scarica i controlli

Il catalogo dei controlli WAF++ contiene le 83+ regole che WAFPass usa per valutare il tuo codice.

bash
$ git clone https://github.com/WAF2p/framework.git controls-src
$ cp -r controls-src/modules/controls/controls ./controls

Consigliato: clona il repo dei controlli. Alternativa: scarica lo zip dei controlli dalla pagina WAFPass ed estrailo in controls/.

3

Salva un file Terraform di esempio

Crea un main.tf minimale. Questo esempio lascia deliberatamente un bucket S3 pubblico in modo che WAFPass abbia qualcosa da segnalare.

provider "aws" {
  region = "eu-central-1"
}

resource "aws_s3_bucket" "public" {
  bucket = "wafpp-first-check-demo"
}

resource "aws_s3_bucket_public_access_block" "public" {
  bucket                  = aws_s3_bucket.public.id
  block_public_acls       = false
  block_public_policy     = false
  ignore_public_acls      = false
  restrict_public_buckets = false
}
4

Esegui il tuo primo controllo

Punta WAFPass sulla directory corrente e stampa il riepilogo JSON.

bash
$ wafpass check . --output json | jq '.summary'

Dovresti vedere un output come questo:

{
  "total_controls": 83,
  "passed": 81,
  "failed": 2,
  "pillars": {
    "security": { "passed": 18, "failed": 2 }
  }
}
81 passed — le risorse soddisfano il controllo
2 failed — le risorse violano un controllo (qui, il bucket S3 pubblico)
83 controls — regole totali valutate sui 8 pilastri WAF++

Esegui la dashboard completa in locale

Il monorepo WAF2p/pass include un docker-compose.yml unificato. Avvia CLI, server, dashboard, PostgreSQL e Keycloak con un solo comando.

bash
$ git clone https://github.com/WAF2p/pass.git
$ cd pass
$ cp .env.example .env
$ # Edit .env — set POSTGRES_PASSWORD, WAFPASS_JWT_SECRET, etc.
$ docker compose up -d

Aggiungi a CI / pre-commit

Blocca l'infrastruttura non conforme prima che raggiunga il tuo branch principale. WAFPass gira interamente sui file del repo, quindi i controlli CI sono veloci e non richiedono segreti cloud.

1

Installa il hook pre-commit

Esegui lo script di installazione dal repository WAFPass una volta per clone. Dopo di che, ogni git commit viene verificato automaticamente.

bash
$ bash hooks/install.sh # macOS / Linux / Git Bash
$ .\hooks\install.ps1 # Windows PowerShell
2

Aggiungi WAFPass a GitHub Actions

Usa l'azione GitHub ufficiale di WAFPass per far fallire le pull request che introducono errori di configurazione. Funziona con repository pubblici e privati.

Configurazione avanzata / manuale

Installa solo i componenti di cui hai bisogno. Inizia con la CLI per CI/CD, poi aggiungi server e dashboard quando ti servono persistenza ed esplorazione visiva.

1
Installa la CLI wafpass

Motore di valutazione core — analizza IaC, valuta i controlli, genera report

Da PyPI (consigliato)

bash
$ pip install wafpass-core
$ uv add wafpass-core # consigliato per progetti Python

Dal codice sorgente

bash
$ git clone https://github.com/WAF2p/pass.git
$ cd pass
$ uv pip install -e . # consigliato
$ pip install -e ".[pdf]" # con supporto report PDF

macOS (serie Apple M)

bash
$ brew install git python uv
$ git clone https://github.com/WAF2p/pass.git && cd pass
$ uv pip install -e .
$ wafpass --version # verifica installazione
2
Installa wafpass-server

Layer di persistenza FastAPI — memorizza esecuzioni, deroghe, risultati sui segreti ed eventi di audit

Da PyPI (consigliato)

bash
$ pip install wafpass-server
$ uv add wafpass-server # consigliato per progetti Python

Configura e avvia

bash
$ cp .env.example .env # imposta DATABASE_URL e il segreto JWT
$ alembic upgrade head # applica le migrazioni del database
$ uvicorn wafpass_server.main:app --reload --port 8000

Documentazione API disponibile presso http://localhost:8000/api/docs

3
Installa wafpass-dashboard

Dashboard web React — 22+ viste di compliance, esportazione di evidenze, RBAC

bash
$ git clone https://github.com/WAF2p/wafpass-dashboard.git
$ cd wafpass-dashboard
$ npm install
$ cp .env.example .env.local # imposta VITE_API_URL
$ npm run dev # server dev all'indirizzo http://localhost:5173
RISOLUZIONE DEI PROBLEMI

Problemi comuni e soluzioni.

Risposte rapide se qualcosa non funziona al primo tentativo.

Controlli non trovati

Se wafpass check segnala "controls directory not found", la CLI mostrerà automaticamente le istruzioni per il download. Assicurati che la cartella controls/ si trovi accanto a dove esegui le scansioni.

Porta già in uso

Usa una porta diversa per il server o la dashboard:

$ uvicorn wafpass_server.main:app --port 8001
$ npm run dev -- --port 5174
Errori di connessione al database

Verifica che PostgreSQL sia in esecuzione e che il tuo DATABASE_URL sia corretto:

$ psql $DATABASE_URL -c "SELECT 1"
Build Docker fallisce

Assicurati che tutti e tre i repository siano clonati fianco a fianco nella stessa directory padre quando fai la build dal codice sorgente:

$ ls -1
pass/
wafpass-server/
wafpass-dashboard/
