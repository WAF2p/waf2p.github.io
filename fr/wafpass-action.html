Une étape. Une visibilité complète.

L'action gère l'installation de la CLI, l'analyse, l'envoi des résultats et l'application des politiques, pour que votre équipe se concentre sur la livraison.

Installation automatique de la CLI

Installe automatiquement la dernière version de wafpass-core depuis PyPI, ou utilisez une source pip personnalisée ou un binaire préinstallé.

Analyse multi-IaC

Analysez des fichiers Terraform, Bicep, CDK ou Pulumi en une seule étape. Prend en charge plusieurs chemins et le JSON de plan Terraform pour visualiser les changements.

Envoi au serveur

Envoie le wafpass-result.json complet vers POST /api/v1/runs pour que les tableaux de bord et les paquets de preuves restent à jour.

Portes de politiques

Politiques fail_on configurables, de never à critical. L'étape n'échoue qu'une fois le résultat enregistré en toute sécurité sur le serveur.

Authentification flexible

Utilisez un jeton Bearer pour les utilisateurs interactifs ou une clé d'API d'ingestion pour les exécutions CI/CD sans interface. Les deux sont transmis de façon sécurisée au serveur.

Métadonnées CI/CD

Marque les exécutions comme is_cicd: true avec triggered_by: github-actions, et transmet automatiquement la branche, le SHA du commit, le projet et l'environnement.

Ajoutez-la à n'importe quel workflow.

Récupérez votre dépôt, lancez l'action et affichez les résultats de conformité là où votre équipe travaille déjà.

.github/workflows/wafpass.yml
{% raw %}
name: WAF++ PASS Scan

on:
  push:
    branches: [main, develop]
  pull_request:

jobs:
  wafpass:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Run WAF++ PASS
        uses: WAF2p/wafpass-action@v0.1.1
        with:
          server_url: ${{ vars.WAFPASS_SERVER_URL }}
          api_key: ${{ secrets.WAFPASS_API_KEY }}
          scan_path: ./infra
          iac_framework: terraform
          project: ${{ github.repository }}
          stage: ${{ github.ref_name == 'main' && 'prod' || 'dev' }}
          fail_on: high
          upload_source: true
{% endraw %}
