Licences légales &

WAF++ utilise un modèle à double licence : Apache License 2.0 pour code et Creative Commons Attribution 4.0 (CC BY 4.0) pour la documentation. Ce modèle est compatible avec le CNCF et prêt pour la fondation.

Double licence

Deux licences, un cadre

Le modèle à double licence maintient WAF++ ouvert, utilisable commercialement et prêt au CNCF, sans ambiguïté sur ce que vous pouvez en faire.

Code → Apache 2.0

Tous les éléments de code source, d'outillage et de cadre, y compris WAFPass. L'utilisation commerciale, la modification et la redistribution sont explicitement autorisées. Comprend la délivrance de brevets.

Documentation → CC BY 4.0

Tout le contenu écrit, les guides, la documentation du pilier, les diapositives et le matériel de référence. Partager et s'adapter librement — attribution à WAF++ requise.

Contributions

En soumettant une demande de tirage, vous acceptez que votre contribution soit publiée sous la licence de projet correspondante (Apache 2.0 pour code, CC BY 4.0 pour docs).

Licence de code

Licence Apache 2.0

Tous les codes sources, WAFPass, plugins et outils WAF++ sont publiés sous la licence Apache 2.0, l'une des licences open-source les plus permissives et largement adoptées.

Permis

Usage commercial

Utilisez WAFPass et tous les codes-cadres dans les produits commerciaux, les outils internes et les offres SaaS sans aucune redevance ni restriction.

Permis

Modification & redistribution

Fourche, modifie et redistribue le code librement. Vous pouvez distribuer des versions modifiées selon vos propres modalités tant que la licence originale est conservée.

Inclus

Octroi explicite de brevets

Les contributeurs délivrent une licence de brevet explicite et libre de redevances qui couvre tous les brevets qui s'appliquent à leurs contributions — la protection des utilisateurs en aval.

Non requis

Aucune obligation de copyleft

Aucune obligation d'ouvrir votre propre code lorsque vous utilisez des composants WAF++. Les intégrations propriétaires sont entièrement autorisées.

Licence de documentation

Creative Commons PAR 4.0

Toute la documentation WAF++, les guides des piliers, les diapositives, les documents de référence et le contenu écrit sont publiés sous CC BY 4.0.

Ce que vous pouvez faire

  • Partager— copier et redistribuer le matériel dans tout support ou format
  • Adapter— remixer, transformer et construire sur le matériau
  • Usage commercial— utiliser la documentation à n'importe quelle fin, y compris commerciale

Une condition

  • Attribution requise— vous devez accorder le crédit approprié à WAF++, fournir un lien vers la licence et indiquer si des modifications ont été apportées.

Avertissement

WAF++ est fourni sans garantie expresse ou implicite. L'utilisation du cadre est à vos propres risques.

Le cadre ne remplace pas les avis juridiques, la certification officielle ou les évaluations de conformité. Il fournit des conseils, des modèles d'évaluation et des critères traçables.

Contribution & conformité
