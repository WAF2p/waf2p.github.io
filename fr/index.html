pip install wafpass-core
02
Exécutez une commande

Pointez WAFPass vers votre dossier Terraform et obtenez un résumé JSON.

wafpass check . --output json | jq '.summary'
03

À quoi ressemble une première constatation

WAFPass signale un bucket S3 public et affiche le contrôle exact et la correction.

FAIL SEC-S3-001

Le blocage de l'accès public au bucket S3 est désactivé. Les buckets publics exposent des données sur Internet.

Extrait de correction
resource "aws_s3_bucket_public_access_block" "public" {
  bucket                  = aws_s3_bucket.public.id
  block_public_acls       = true
  block_public_policy     = true
  ignore_public_acls      = true
  restrict_public_buckets = true
}
