Wombat·Anciennement WAF++

L'avenir de l'architecture cloud commence aujourd'hui.

Wombat est un framework ouvert et agnostique vis-à-vis du cloud qui rend votre infrastructure souveraine, sécurisée et prête pour l'audit, avec plus de 100 contrôles répartis sur 8 piliers.

Le moment est venu !

Pendant des années, les revues d'architecture cloud ont rimé avec dépendance à un seul fournisseur, checklists de conformité de façade ou consultants armés de slides. Wombat repart de zéro : un framework neutre vis-à-vis des fournisseurs, une CLI statique qui lit votre code et des preuves que chacun peut vérifier.

Du code à la preuve.

{% include home-mascot.html variant="steps" text="Trois étapes. Aucun identifiant." %}
D'abord

Écrivez du Terraform

Construisez votre infrastructure as code comme d'habitude. Wombat reste en dehors de votre workflow jusqu'à ce que vous le lanciez.

Ensuite

Lancez WOMBATpass

Une analyse statique vérifie chaque ressource par rapport aux plus de 100 contrôles du framework avec wombat check . --output json. Aucun identifiant, aucun appel d'API vers votre compte cloud.

Enfin

Livrez avec des preuves

Exportez l'exécution en PDF prêt pour les auditeurs, ou scellez-la dans un paquet de preuves que chacun peut vérifier de façon indépendante.
