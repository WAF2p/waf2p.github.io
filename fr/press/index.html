Texte de présentation validé.

Utilisez les textes suivants pour présenter WAF++ dans des articles, podcasts ou présentations.

Court (1 phrase)

WAF++ est un framework open source et neutre vis-à-vis des fournisseurs pour évaluer et améliorer la qualité des workloads cloud selon 8 piliers : Security, Reliability, Performance Efficiency, Cost Optimisation, Operational Excellence, Sustainability, Sovereign et Agentic.

Réseaux sociaux / format court (≤ 280 caractères)

WAF++ est un framework open source et neutre pour la qualité des architectures cloud : 8 piliers, scoring transparent, gouvernance communautaire via des RFC publiques. Docs sous CC BY 4.0, code sous Apache 2.0. waf2p.dev

Standard (2–3 phrases)

WAF++ (Well-Architected Framework Plus Plus) est un framework open source et communautaire pour évaluer et améliorer la qualité des workloads cloud. Il couvre 8 piliers — Security, Reliability, Performance Efficiency, Cost Optimisation, Operational Excellence, Sustainability, Sovereign et Agentic — avec un modèle de scoring transparent appelé PASS.

Contrairement aux frameworks propriétaires des fournisseurs, WAF++ est gouverné ouvertement via des RFC dans GitHub Discussions : chaque décision est traçable et chaque contrôle citable. Le framework est libre d'utilisation, ouvert aux contributions et à la réutilisation.

Introduction podcast / interview

WAF++ — prononcé « waf plus plus » — est un framework open source qui offre aux équipes d'ingénierie et d'architecture un regard neutre pour évaluer leurs workloads cloud. Il s'organise autour de huit piliers : Security, Reliability, Performance Efficiency, Cost Optimisation, Operational Excellence, Sustainability, Sovereign et Agentic.

Ce qui distingue WAF++, c'est sa manière d'être construit : chaque recommandation, règle de scoring et décision de conception passe par un processus RFC public sur GitHub, entièrement transparent et entièrement communautaire. Aucun fournisseur derrière, aucune vente additionnelle, aucune boîte noire. Chacun peut lire les critères, les contester et les améliorer.

Règles d'usage de la marque.

Comment désigner correctement WAF++ dans un contenu éditorial.

À faire

Écrire le nom du projet WAF++ — deux signes plus, en majuscules
Utiliser les fichiers de logo non modifiés de cette page
Créditer ainsi : « WAF++, framework open source d'architecture cloud »
Mettre un lien vers waf2p.dev pour les lecteurs qui veulent en savoir plus

À éviter

Ne pas modifier les couleurs ou les proportions du logo, ni ajouter d'effets
Ne pas suggérer de soutien ou de partenariat officiel sans autorisation écrite
Ne pas utiliser les éléments WAF++ d'une manière qui dénature le périmètre ou la gouvernance du projet
Ne pas utiliser le nom dans des noms de produits ou de services sans autorisation
