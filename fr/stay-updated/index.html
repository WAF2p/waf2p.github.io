Comment suivre Wombat.

Choisissez-en un ou les trois : chaque canal est gratuit et ouvert. Pas de newsletter, pas de pistage, pas de bruit.

Flux RSS / Atom

Abonnez-vous au flux RSS du blog et recevez les nouveaux articles directement dans votre lecteur. Sans compte, sans inscription.

S'abonner au RSS →

Communauté Slack

Rejoignez le Slack de Wombat. Retrouvez les annonces dans #announcements, discutez des versions dans #general et posez vos questions à tout moment.

Rejoindre Slack →

GitHub

Suivez ou ajoutez une étoile au dépôt pour être averti des versions, issues et PR. Suivez les Discussions pour les RFC et les décisions de la communauté.

Suivre sur GitHub →
