Projet open source Wombat.

Wombat est un framework open source porté par la communauté. Le projet n'est actuellement pas une personne morale enregistrée (par exemple une association ou une fondation).

Wombat – Cloud Governance & IaC Validation

Un framework neutre, maintenu par la communauté, pour évaluer la qualité des architectures cloud.
