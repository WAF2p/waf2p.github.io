## Framework & WOMBATpass changes

### October 2026

- Rebrand: WAF++ is now Wombat, the software is WOMBATpass and the CLI command is wombat. New wombat logo, favicon and press assets; the site moves to www.wombat-gov.dev and the one-line installers to wombat-cli.dev
- New 404 page "Lost in the underground" with the wombat illustration, in all eight languages

### October 2026 — v1.1.0

- Machine-readable control schema — added category, rationale, threat, implementation guidance, maturity levels, evidence, and references to all 83 controls
- Multi-provider Terraform coverage — expanded checks for AWS, Azure, GCP, StackIT, OVHcloud, and Hetzner Cloud across Security, Sovereign, and other pillars
- Compilable dummy code examples — added main.tf and non_compliant.tf samples for all six providers to validate checker assertions
- Framework version 1.1.0 — adopted 1.1.0 across German and English Antora component metadata, documentation URLs, and website links
- OVHcloud data-residency check — converted WAF-SOV-010 OVH check from unsupported Terraform tags to config/file-based policy verification
- Schema normalization — closed control type and on_fail taxonomies; corrected provider scopes and StackIT resource naming
